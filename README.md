# NGHIENGAME_BOT

Telegram bot built with Python and Aiogram 3.

## Required environment variables

- `BOT_TOKEN`: Telegram bot token (keep secret; never commit it).
- `ADM_IDS`: comma-separated Telegram admin IDs.

## Run locally

```bash
python -m pip install -r requirements.txt
python main.py
```

Railway start command: `python main.py`.

The initial deployment includes the main menu, category navigation, account identity display, help page, and admin access gate. Order processing, balance/payment, code inventory delivery, and SMS/PRX provider integrations must be configured and tested before enabling sales.
